Core Pillars

Built for Speed, Privacy & Simplicity

Every feature in Rook Lite was crafted to respect your attention and preserve your digital ownership.

True Local-First Storage with IndexedDB

Powered by idb with strict schema versioning and transactional guarantees. Notes, categories, summaries, and drafts live in structured stores in your browser. Reads and writes are instantaneous and survive reboots and network loss.

// Direct IndexedDB object store access (0ms network latency)
const db = await openDB('rook-lite-db', 1);
await db.put('notes', { id, title, content, date, tags, categoryId });

Dual-Engine Summaries

Choose deterministic rule-based category digests, or plug directly into your local Ollama instance (Llama 3.2, Mistral, Qwen) with zero third-party cloud data transmission.

Markdown-Native & Tasks

GitHub-Flavored Markdown parsed with Marked and sanitized through DOMPurify. Interactive checklists allow instant task completion right from the reading view.

Zero Lock-in Data Portability

Complete JSON v1 backup/restore, directory exports via the browser File System Access API, and zipped Markdown packages via lightweight fflate.

Loopback-Restricted Security

Ollama AI endpoints are hard-validated against loopback interfaces (127.0.0.1, localhost, [::1]). The app refuses arbitrary outbound network calls.

// Step 1: Start Ollama with browser origin support

Deployment

Run anywhere in seconds. Zero dependencies.

Rook Lite is completely stateless. You can run it via Docker, clone and build it with Node, or deploy the static assets to GitHub Pages or any CDN.

  • Lightweight Multi-Stage Docker: Alpine Nginx image with healthchecks
  • Subpath Aware: Deploy to any subpath or root domain without broken links
  • PWA Ready: Install directly on desktop or mobile with offline worker
# 1. Build the lightweight production container
docker build -t rook-lite .

# 2. Run container (stateless Nginx server on port 8080)
docker run --rm -p 8080:8080 rook-lite

# 3. Open browser at:
http://localhost:8080
# 1. Clone repository
git clone https://github.com/volkanto/rook-lite.git && cd rook-lite

# 2. Install dependencies & start dev server
npm install && npm run dev

# 3. Open local development server at:
http://localhost:5173
# Compile TypeScript & bundle assets for production
npm run build

# For subpath deployments (e.g. GitHub Pages):
VITE_BASE_PATH="/rook-lite/" npm run build

# Production static bundle ready in:
dist/

Everything you need to know about Rook Lite's local-first architecture and security.

Your data is stored 100% locally on your machine inside your browser's IndexedDB database (rook-lite-db). There are no remote sync databases, telemetry servers, or third-party cloud mirrors. If your internet connection goes down, Rook Lite continues to work without interruption.
No. Rook Lite strictly prohibits remote AI endpoints. The Ollama integration is cryptographically and logically restricted to verified loopback addresses (localhost, 127.0.0.1, and [::1]). Your notes are sent only to your own locally running Ollama process over local IPC/loopback.
Clearing temporary cache does not delete IndexedDB, but clearing "site cookies and data" for the origin will wipe browser storage.
