# iOS Native App Implementation Plan

## Objective
Develop a fully native, local-first iOS mobile application for Rook Lite using SwiftUI and SwiftData, optimized for touch interfaces while retaining all offline capabilities.

## Key Files & Context
- **Target Directory:** `ios/`
- **Architecture:** MVVM + SwiftData
- **UI Framework:** SwiftUI
- **Database:** SwiftData
- **AI Integration:** Local network Ollama access via `URLSession`

## Scope & Impact
- **Models:** Share or replicate the SwiftData `@Model` classes (Notes, Categories, Drafts, Summaries).
- **UI/UX:** Mobile-first layout using `NavigationStack` and `TabView`, tailored for smaller screens and safe area insets (Notch/Dynamic Island).
- **Markdown:** Implement a touch-friendly Markdown editor with custom keyboard accessory toolbars for formatting.
- **AI Connectivity:** Implement network connectivity that can reach a desktop Ollama instance on the local LAN.

## Implementation Steps

### Phase 1: Project Setup & SwiftData Models
1. Create a new Xcode iOS project in the `ios/` directory (or a shared multi-platform workspace if preferred, but logically distinct for mobile UI).
2. Define SwiftData `@Model` entities matching the core data structures.
3. Setup the local `ModelContainer`.

### Phase 2: Mobile UI & Navigation
1. Construct the primary navigation using a `TabView` (e.g., Notes, Categories, Summaries, Settings) and `NavigationStack` for drill-down interactions.
2. Implement the Note List with swipe actions (delete, pin, move).
3. Develop the Mobile Note Editor. Include a custom input accessory view (toolbar above the keyboard) to quickly insert Markdown syntax (bold, lists, headings).
4. Implement a sheet or full-screen cover for the Markdown preview mode.

### Phase 3: AI Integration on Mobile
1. Implement the `OllamaService` with a configurable host IP in Settings, as iOS cannot reliably use `localhost` to reach a macOS host.
2. Update `Info.plist` with `NSLocalNetworkUsageDescription` and `NSAppTransportSecurity` (ATS) exceptions if necessary to allow local network HTTP requests.
3. Implement the native offline rule-based summarizer as a fallback when Ollama is unreachable.

### Phase 4: Import, Export & System Integration
1. Integrate with iOS `ShareSheet` (`UIActivityViewController`) and `UIDocumentPickerViewController` to allow users to export backups to Files or iCloud Drive.
2. Support iOS dynamic typography and accessibility settings.
3. Add haptic feedback for key interactions (saving, deleting, AI generation completion).

## Verification & Testing
- Test across various iOS device sizes (iPhone SE, iPhone Pro Max) and orientations in the Simulator.
- Verify safe area handling around the Dynamic Island and Home Indicator.
- Ensure the local network permission prompt appears and Ollama connectivity works when provided a valid LAN IP.

## Migration & Rollback
- The web app is unaffected.
- The iOS app should support importing the JSON backup generated by the web application via the iOS Files app.
